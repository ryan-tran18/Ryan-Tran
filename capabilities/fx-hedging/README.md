# FX Hedging Model

This capability evaluates foreign-exchange transaction hedging strategies for companies with future foreign-currency receivables or payables.

It compares forward contracts, money-market hedges, and currency options to help treasury teams understand the trade-offs between certainty, cost, and potential exchange-rate outcomes.
